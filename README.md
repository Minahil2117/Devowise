# Devowise Website Redesign

A modern, responsive redesign of the **Devowise** website, focused on creating a clean, professional, and engaging digital experience inspired by modern technology and software company websites.


## Live Link: https://devowise-myweb.vercel.app/
## Overview

This project was developed as part of a frontend redesign task for Devowise. The goal was to transform the existing website into a more modern, visually appealing, and responsive interface while maintaining a professional technology-focused identity.

The redesign focuses on:

* Modern UI/UX
* Responsive layouts
* Smooth animations and interactions
* Strong visual hierarchy
* Professional technology-focused branding
* Clean and reusable React components
* Fast Vite-based development and production builds

## Tech Stack

* **React** — UI development
* **Vite** — Development and production build tool
* **TypeScript** — Type-safe development
* **Tailwind CSS v4** — Styling and responsive design
* **React 19** — Frontend framework
* **Lucide React** — Icons
* **Framer Motion** — Animations and interactions
* **vite-plugin-singlefile** — Single-file build support

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Minahil2117/Devowise.git
```

### 2. Navigate to the project

```bash
cd Devowise
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.

## Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Deployment

The project is configured for deployment with **Vercel**.

Every new push to the `main` branch can trigger a new deployment when the GitHub repository is connected to Vercel.

## Design Goals

The redesign was created with the following principles:

1. **Clean** — Avoid unnecessary visual clutter.
2. **Modern** — Use contemporary web design patterns.
3. **Responsive** — Provide a consistent experience across devices.
4. **Interactive** — Use subtle animations and transitions.
5. **Professional** — Maintain a strong software/technology-company identity.
6. **Performance-focused** — Keep the application lightweight and optimized.

## Development

This project uses a component-based architecture to make the interface easier to maintain and extend.

The project also keeps generated files such as `node_modules` and production output out of version control using `.gitignore`.
